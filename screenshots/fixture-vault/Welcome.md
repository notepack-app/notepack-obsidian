# Welcome

Demo vault for the **NotePack** Obsidian plugin.

## What's here

- `Team/` — four team members with aliases for `@mention` assignment
- `Meetings/` — dated meeting notes with `## Follow-up` sections
- `1-1s/` — 1:1 notes with assigned todos
- `Projects/` — long-running project tracking notes
- `Personal.md` — own todos (unassigned)
- `Archive/` — file using `excludeTodos: true` to demo the skip flag

## Try

- Command palette → **NotePack: Show my todos**
- Command palette → **NotePack: Show team todos**
- Command palette → **NotePack: Show recent files**
- Command palette → **NotePack: Export todos and recent files to file system**
